# Student Record System

A simple Python project to manage student records using Python.

## Features
- Add student
- View all students
- Search student
- Clear records
- File-based storage
- Exception handling

## Concepts Used
- Variables
- Loops
- Conditions
- File Handling
- Exception Handling

## Run Project

```bash
python student_record_system.py
```
